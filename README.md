Mission — Revenus en ligne

Application web mobile/PWA en français pour organiser les candidatures, les tâches et les paiements de plusieurs plateformes de missions en ligne.

Fonctionnalités : liens officiels vers TELUS Digital AI, CrowdGen, Outlier, DataAnnotation, Prolific et UserTesting ; création, modification, filtrage et suppression des tâches ; statuts à faire/en cours/terminée ; suivi du temps, gains déclarés et paiements reçus ; données locales et export JSON ; interface responsive et cache hors ligne basique.

Limites : l’application organise le travail mais ne récupère pas automatiquement les offres, ne soumet pas de candidatures et ne garantit aucun revenu. Vérifie les critères, les tâches et les moyens de paiement sur les sites officiels. Ne paie jamais pour obtenir un emploi. Les données sont locales à cet appareil/navigateur ; exporte une sauvegarde régulièrement.

Déploiement GitHub Pages : Settings → Pages → Deploy from a branch → branche main → dossier /(root) → Save. Attends la publication et ouvre l’URL affichée.

Sur iPhone : ouvre le site dans Safari → Partager → Sur l’écran d’accueil.
